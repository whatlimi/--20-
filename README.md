# 数学乐园 🎈

> 20 以内加减法练习应用 · 单文件 HTML · 面向小学生

一个专为 5 岁以上小学生设计的加减法练习应用，以"动物乐园"为主题，让孩子在收集宠物伙伴的过程中快乐练习 20 以内的加减法（含进位退位、括号填空）。

## ✨ 功能特性

### 核心玩法
- **20 套题 × 每套 10 题**通关制，共 200 题
- **题型**：加减混合（含进位/退位）+ 括号填空（如 `( ) + 5 = 8`），固定混合模式
- **作答方式**：键盘输入答案 + 确认按钮（移动端自动弹数字键盘，Enter 提交）
- **必须答对才放行**下一题，不允许跳过

### 宠美伙伴收集系统
- **20 只点亮宠物**：初始全灰，孩子选择一只要的 → 全对一套题即获得（点亮）它
- **封面页选宠**：20 只宠物全灰展示，hover 放大，点击框选，点"开始"进入答题
- **内页目标展示**：答题页显示"🎯 全对获得 🐰跳跳"激励孩子
- **5 只陪伴宠物**：答题页右上角可点击切换，独立于点亮系统，随时可用
- **未全对鼓励重做**：差一点全对时弹窗"再试一次，全对就能获得 🐰跳跳！"+ "重做这套"按钮

### 答错讲解动画
- 答错弹窗自动播放**分步动画演示**解题过程：
  - **凑十法**（进位加法）：看大数 → 拆小数 → 凑 10 → 10+余=答案（4 步）
  - **破十法**（退位减法）：十位+个位 → 划掉块 → 剩+个位=答案（3 步）
  - **倒推法**（括号填空）：原题重写 → 倒推算式 → 答案填括号（3 步）
- 每秒推进一步，方块图 + 说明文字 + 高亮算式
- 弹窗轻量四要素：伙伴头像 + 鼓励语 + "你输入的：X，正确答案应该为 Y" + 动画 + "重新答题"按钮

### 激励机制
- **饼干收集制**：答对得饼干（加法 1 块 / 减法填空 2 块，弱项加权），答错不扣
- **收集不可逆**：重做/重置不清除已获得的饼干和宠物
- **进度可视化**：HUD 显示饼干数 + 已点亮宠物数 / 20

### 响应式适配
- 适配手机、平板、桌面多尺寸（@media 断点覆盖）
- 封面页、答题页、弹窗、方块图在各尺寸下布局正常

## 🚀 使用方法

### 直接使用
1. 下载 `math-20.html`
2. 双击用浏览器打开即可（无需安装、无需服务器、无依赖）

### 数据存储
- 所有进度（饼干、已点亮宠物、陪伴宠物、静音设置）存储在浏览器 `localStorage`
- 关闭重开不丢失，换浏览器/清缓存会重置

## 🛠️ 技术栈

- **纯单文件 HTML**：所有 CSS / JS 内联，零外部依赖，零构建链
- **Vanilla JavaScript**：无框架无库
- **CSS 动画**：方块图 + fadeUp/pop/pulse 关键帧
- **Web Audio API**：答对/答错/升级音效
- **localStorage**：持久化存储

## 🎮 交互流程

```
封面页（20 只宠物全灰）
  ├─ hover 宠物 → 放大（保持灰色）
  ├─ 点击宠物 → 框选（绿色边框，可反复换选）
  ├─ 点击"开始" → 进入答题页
  │
答题页
  ├─ 显示"🎯 全对获得 🐰跳跳"（目标宠物）
  ├─ 键盘输入答案 → 确认
  │   ├─ 答对 → 饼干 + 下一题
  │   └─ 答错 → 弹窗动画讲解 → 重新答题（不跳题）
  ├─ 右上角陪伴宠物可点击切换（5 只）
  └─ 10 题完成 → 套总结弹窗
      ├─ 全对 → 点亮目标宠物 🎉 + 撒花播报
      ├─ 没全对 → "差一点点！重做这套 ✏️"
      └─ 下一套 → 宠美选择面板（20 只全显示，已点亮亮色不可选）
```
